# Unity 전략 패턴 공격 시스템 (UnityTest)

이 프로젝트는 유니티에서 **전략 패턴(Strategy Pattern)**을 사용하여 캐릭터의 공격 방식(근접, 원거리)을 동적으로 교체하는 방법을 보여주는 테스트 프로젝트입니다.

## 🚀 주요 특징
- **인터페이스 기반 설계**: IAction 인터페이스를 사용하여 공격 로직과 플레이어 클래스 간의 의존성을 분리했습니다.
- **Enum 기반 교체**: 유니티 인스펙터의 Enum 드롭다운을 통해 공격 모드를 쉽게 바꿀 수 있습니다.
- **컴포넌트 자동 동기화**: GetComponents를 통해 오브젝트에 부착된 공격 스크립트를 자동으로 찾아 할당합니다.
- **에디터 최적화**: OnValidate를 활용하여 에디터에서 값을 변경하는 즉시 전략이 업데이트되도록 구현했습니다.

## 🛠 시스템 구조

### 1. IAction 인터페이스
모든 공격 전략이 공통으로 구현해야 할 규격입니다. Attack() 메서드를 포함합니다.

### 2. 구체적인 전략 구현
각 공격 방식의 실제 로직을 정의하는 클래스입니다.
- MeleeAttack: 근거리 칼 공격 로직을 구현합니다.
- BowAttack: 원거리 활 공격 로직을 구현합니다.

### 3. 플레이어 컨트롤러 (Player.cs)
현재 어떤 공격 전략을 사용할지 결정하고 실행하는 주체입니다. AttackMethod Enum 값에 따라 현재 전략을 관리합니다.

## ⚙️ 설정 및 사용 방법

1. 컴포넌트 부착: Player 게임 오브젝트에 Player.cs, MeleeAttack.cs, BowAttack.cs 스크립트를 모두 추가합니다.
2. 모드 선택: 인스펙터 창의 Current Method 항목에서 Melee 또는 Bow 중 하나를 선택합니다.
3. 테스트: 게임 실행 후 마우스 왼쪽 클릭을 하면 선택된 모드에 맞는 공격 로그가 콘솔창에 출력됩니다.

## 📂 프로젝트 파일 구조
- Player.cs: 전략 교체 및 실행을 관리하는 메인 스크립트
- IAction.cs: 공격 메서드 정의를 위한 인터페이스
- MeleeAttack.cs: 근접 공격 기능 구현 컴포넌트
- BowAttack.cs: 원거리 공격 기능 구현 컴포넌트
